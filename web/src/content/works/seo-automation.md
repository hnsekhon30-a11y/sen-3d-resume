## Goal

Build an automated SEO audit workflow inspired by technical crawling tools.

## Workflow

Collect URLs → inspect technical signals → normalize findings → classify issues → generate an AI-assisted audit summary.

## Focus

- Crawl-oriented workflows
- Technical SEO checks
- Structured findings
- Automation with n8n
- AI-generated recommendations

The objective is to reduce repetitive manual audit work while keeping findings traceable.
