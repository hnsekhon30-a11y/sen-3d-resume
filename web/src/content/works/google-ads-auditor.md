## Problem

Keyword-level Google Ads audits can require repetitive filtering, metric comparison and manual identification of optimization opportunities.

## Solution

A Streamlit utility that connects campaign data to an audit interface and organizes keywords into actionable performance buckets.

## Features

- Google Ads API integration
- Keyword performance metrics
- Quality Score analysis
- Negative keyword opportunities
- Performance bucketing
- AI-assisted analysis using Groq

## Stack

Python · Streamlit · Google Ads API · Groq
