# Google Ads Health Checker

**AI-powered advertising diagnostics**

## Overview
A Google Ads auditing project focused on automating account diagnostics and surfacing actionable performance issues.

## Focus
- Google Ads API data
- Keyword and campaign diagnostics
- Performance metrics and quality signals
- Python / Streamlit application workflow
- AI-assisted analysis with Groq

## Why it matters
The project turns repetitive advertising checks into a structured workflow so performance issues and optimization opportunities can be reviewed more efficiently.

## Stack
Python · Streamlit · Google Ads API · Groq
