## Concept

Manifestation Garden turns daily journaling into a visual garden. Each intention becomes a plant that grows when the user consistently returns to it.

## Core loop

Plant an intention → write daily → plant grows → missed days affect plant health → consistency leads to a bloom.

## Product mechanics

Different flowers represent different journey lengths, creating a simple progression system while keeping the experience calm and visual.

## What I explored

Habit loops, emotional UX, gamification, visual feedback and using AI to make a reflective journaling experience more engaging.
